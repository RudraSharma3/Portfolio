# Portfolio

- code/index.html  -> the website (reads from ../assets)
- assets/portrait.jpg  -> replace with your full-quality photo (same name)
- assets/Rudra_Sharma_Resume.pdf  -> replace when your resume changes
- assets/certificates/  -> all certificates and badges
- Project repo links: edit the `link` field of each project in the PR array in code/index.html (set to null for "Repository coming soon").
- Preview: run `python3 -m http.server` inside this folder, open http://localhost:8000/code/
- GitHub Pages: push this folder as repo root.
